# Research Programme Overview

## Working title

**Toward a Multiscale Computational Theory of Education Systems**

## Core objective

Develop a general multiscale computational framework in which heterogeneous agents interact, learn, adapt, and respond to policy over multiple temporal and organizational scales, while established models can be recovered as special cases or approximations.

## Scale hierarchy

```text
Neural / cognitive
→ learner
→ classroom / small group
→ school
→ family / community / market
→ education system
→ society / economy
```

## Core mathematical objects

```text
X = states
A = actions
Pi = decision rules
F = dynamics
G = interaction / network structure
P = policy / institutions
C = cross-scale mappings
O = observation / measurement
```

## Programme rule

Cross-scale consistency does not require literal microscopic simulation. It requires explicit mappings between scales and approximate consistency where domains overlap.
