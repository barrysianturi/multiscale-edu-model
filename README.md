# Multiscale Computational Theory of Education Systems

Canonical research repository structure **v0.1**.

This GitHub repository root is also the **Obsidian vault**.

## Tool roles

- **Mendeley** = evidence library: PDFs, bibliographic metadata, highlights, citations.
- **Obsidian** = thinking and synthesis: concepts, literature notes, model notes, research questions, decisions, paper thinking.
- **GitHub** = source of truth: version control, canonical conventions, registries, code, simulations, manuscripts, reproducibility.

## First setup

1. Create a private GitHub repository named `multiscale-education`.
2. Clone it locally.
3. Copy the contents of this starter pack into the repository root.
4. Commit and push.
5. In Obsidian, choose **Open folder as vault** and select the repository root.
6. Keep Mendeley separate.
7. Read `docs/RESEARCH_OPERATING_MANUAL.md`.
8. Use `00 Home/Research Dashboard.md` as the main navigation page.

## Rule

> If a research convention exists only in chat, memory, or email, it is not yet an official programme convention.

It becomes official when documented in the repository and committed to Git.
